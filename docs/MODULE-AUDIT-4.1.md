# KTHREADD 4.1 module audit

All **54 registered entries** were inspected. The table distinguishes changed behavior from already-correct hooks retained after review. Configuration panels also benefit from common profile recovery and settings search. This is not a claim that every mode has been tested on remote servers.

| AntiChainPop | COMBAT | Upgraded / shared behavior improved | Extends its temporary surround window on repeated local pops, schedules by player ticks, releases owned protection on module disable/disconnect/player change, and preserves an independently enabled surround. [Audit](UPGRADE-COMBAT.md) |
