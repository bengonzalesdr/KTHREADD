# KTHREADD 4.1 upgrade

This development milestone focuses on KTHREADD only, retaining Minecraft 1.20.4 / Fabric / Java 17 and the prior downloadable release for rollback.

## Implemented

- CrystalAura: bounded exposure evaluation count/time, feedback-based placement retry backoff, observed confirmation timing, short motion history with reversal/teleport rejection, latency-adjusted conservative prediction, stable pressure focus, minimum damage-trade filtering, near-first bounded crystal ranking and camera-relative through-wall placement visualization.
- Combat scheduler: action ownership follows player/world tick windows; AutoLog's danger evaluation remains independent of offensive ownership.
- Combat and inventory: stack-aware container looting, tool suitability/Efficiency, charged bows, supported sneaking placements, missing-item fallback, two-hit crystal protection, durability-aware armor, stable melee weapon ownership and stronger critical guards. See [combat audit](UPGRADE-COMBAT.md).
- Movement: deterministic velocity ownership, environmental guards and input restoration, configurable respawn and void rescue, particle-distance budget and independent velocity/explosion controls. See [movement audit](UPGRADE-MOVEMENT.md).
- Rendering/UI: bounded incremental storage scanning, friend/invisibility filters and render caps, richer CPvP HUD, setting-name search, readable themes, atomic backup/recovery and profile menu improvements. Existing through-wall and no-bob pipelines remain. See [visual audit](UPGRADE-VISUALS.md).

## Controls

`/kthread preset balanced`, `aggressive`, or `defensive` applies validated CPvP settings atomically. It does not enable modules or disable self/friend protections. Enable CrystalAura, AutoTotem and AutoArmor as desired. `/kthread set MODULE "SETTING NAME" VALUE` permits exact tuning; mode/text settings are supported. Existing GUI, friend and profile commands remain available.

## Milestone validation

The final integrated build passed **57 unit tests**, **61 targeted local game checks**, and **28 combined production-loader rendering/compatibility checks** with the unchanged SalHack companion. Game checks include actual chest-supported placement, full-charge server bow projectile creation, AntiChainPop ownership cleanup, crystal placement/breaking and spawn reaction, emergency offhand protection, report export and a 64-crystal / 32-evaluation work-bound fixture. All 54 registry entries are covered in the [module audit](MODULE-AUDIT-4.1.md).

These changes do not establish complete original feature parity, every server/modpack/shader configuration, anti-cheat acceptance or competitive superiority. Some already-correct lightweight hooks were audited and preserved rather than given cosmetic settings. The module audit distinguishes those cases.
